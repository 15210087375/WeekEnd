## 搜索页内分段

| 段 | 能力 |
|----|------|
| 搜索 | 关键词 + 类型/辣度/评分 |
| 目录 | 区域→商场→门店（只读；维护请到「我的」） |

## 子页

| path | 说明 |
|------|------|
| `archive/list` | 二级：档案/菜谱列表（`order=1` 为点餐勾选，底栏仅分享/取消；浏览态仅录入） |
| `history/list` | 历史记录 |
| `backup/index` | 数据备份（分模块：菜单/点餐/心愿/全部） |
| `space/index` | 家庭空间（P1：创建/加入/成员；业务同步后续） |
| `order/*` | 点餐清单与分享 |
| `place/*` `region/*` `mall/*` | 门店地理维护 |
| `browse/index` | 兼容跳转 → 搜索 |

## 主路径

1. 美食 → 档案/菜谱 → 录入、点餐分享  
2. 搜索 → 条件检索 或 目录下钻  
3. 我的 → 管理区域 / 备份  
4. 娱乐 → 心愿单（增删改、状态筛选）
