## 三轮核验摘要

### 第 1 轮：需求穷举 vs 代码

| 原计划问题 | 修正 |
|------------|------|
| 家庭能力只写「创建/加入/标签」 | 补全：转让主理、踢人、解散、刷新空间、显示名、createFamily/createSpace、云状态 |
| 未写 cart.checkout / clear | 列入 CART_API，标明与 settle/abandon 关系 |
| 云函数路径写成 miniprogram 下 | 实际为仓库根 `cloudfunctions/wfaSpace` |
| 缺抖音口令/分享口令 | 记入 F6/F7 菜详情能力 |
| 缺默认种子门店/自做挂载 | 记入 F1.6 |
| 心愿「隐私」若未做 | 标「以现网为准」，不臆造 |

### 第 2 轮：架构与阶段依赖

| 原计划问题 | 修正 |
|------------|------|
| 阶段 2 未完成就拆半屏易行为漂移 | **强制：2A/2B/2C 自测通过后再进阶段 3** |
| sync 单入口未点名 API | 定名 `domain.syncRefresh` / `sync.refresh` |
| 半屏防闪补丁删除时机 | 阶段 3 组件独占 setData **之后**删除，禁止先删再拆 |
| 基线测试不可自动化部分 | 阶段 0 交付「清单 + 自测表」；执行中每阶段填 `docs/refactor-logs/` |

### 第 3 轮：遗漏与风险

| 原计划问题 | 修正 |
|------------|------|
| order/share 收分享页 | 补 F5.10 |
| 删除防抖 3s | 保留为 cart 内聚规则 F3.13 |
| 材料 dishId 断链 | 阶段 2A 明确 purge remap 为主路径 |
| 热重载干扰自测 | 自测要求「编译」非热重载 |
| 占位娱乐模块 | F11.2 仅占位，禁止误删入口 |

## 硬原则

1. 修根因，禁止 flag 叠 flag。  
2. 一步一条因果链。  
3. 清单外行为变更必须先改清单。  
4. 每阶段 `docs/refactor-logs/PHx.md` 记录自测。
