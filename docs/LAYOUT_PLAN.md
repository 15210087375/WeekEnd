## 0. 总原则（三条）

1. **一级页只放入口与列表**，说明/统计/备份进二级。  
2. **列表信息优先级**：菜名 > 分类 > 店/区域（或菜谱摘要）> 评分·辣度。  
3. **浏览态 / 点餐态底栏互斥**：浏览=录入；点餐=勾选+「分享给家人」。  

**色板（本项目已用，保持）**

| 业务 | 主色 | 说明 |
|------|------|------|
| 美食档案 | 绿 `#07c160` | 外出 |
| 我的菜谱 | 橙 `#ff8f1f` | 自做 |

（Notebook 曾建议橙=外出、绿=菜谱，**不采纳**，避免与已上线 UI 冲突。）

## 1. 首页（美食 Tab）

**落地状态**：已实现（`pages/home`）。

## 2. 列表页（档案 / 菜谱）

### 2.1 信息与卡片

| 层级 | 内容 |
|------|------|
| 主 | 菜名（粗体、一行省略） |
| 次 | 副线：区域·商场·门店 或 自做挂载 |
| 标签 | 分类胶囊 + 辣度/口味/步骤数 |
| 右 | 评分；浏览态「编辑 ›」；点餐态左侧勾选 |

**可借**：Vant `van-tag` / 卡片节奏；官方字号层次。  
**不抄**：价格、划线价、加购 stepper（商城属性）。

### 2.2 分类筛选

- 顶栏横向滚动芯片：全部 + 炒菜/烧烤/火锅/小吃/饮品/甜点…  
- 可选：`van-sticky` 吸顶，避免抢占过多纵向空间。  
- 筛选不放大说明 Banner（导航栏已有标题）。

### 2.3 点餐多选底栏

| 状态 | 底栏 |
|------|------|
| 浏览 | 「点餐」+「录入美食/录菜谱」 |
| 点餐 | 「取消」+「点餐 N」→ 生成清单 → 详情页分享 |

**注意（Vant）**：`van-submit-bar` 可能与原生 TabBar 重叠；点餐态需给列表 `padding-bottom`，Tab 页若用 SubmitBar 需评估隐藏 Tab 或只用自定义底栏（当前自研 fab-bar 已够用）。  
**不抄**：外卖加减数量、金额合计、支付。

**落地状态**：分类筛选 + 点餐模式已实现；UI 可逐步换成 Vant 组件。

## 3. 详情 / 录入

### 3.1 详情

- 顶：业务类型角标（美食档案 / 我的菜谱）  
- 名 + 评分  
- 门店副线（外出）  
- 分类 + 辣度/口味  
- 图；自做：用料 → 步骤 → 视频  
- 底栏：删除 | 编辑  

**不抄**：SKU、库存、扫码核销、社交瀑布流。

### 3.2 录入表单

- **少打字、多点选**：分类/辣度/评分用芯片（已有）。  
- 外出：菜名、分类、门店、评分、辣度、口味、备注、图。  
- 自做：菜谱名、分类、用料、步骤、视频、备注、图、可选自评。  
- 保存条固定底部。  

**可借**：WeUI Form / Cell；Vant Field、Uploader、Tag。  
**不抄**：纯 Markdown 编辑器作主录入。

## 6. UI 开源库（已下载）

| 库 | 路径 | 用途 |
|----|------|------|
| **@vant/weapp** | `miniprogram/node_modules/@vant/weapp` | Tag / Sticky / SubmitBar / Field / Uploader / Empty / Toast |

### 使用前（微信开发者工具）

1. 打开项目根：`D:\Habby\food`  
2. 详情 → 本地设置 → **使用 npm 模块**  
3. 工具 → **构建 npm** → 生成 `miniprogram/miniprogram_npm`  
4. 页面 json 中引用示例：

```json
{
  "usingComponents": {
    "van-tag": "@vant/weapp/tag/index",
    "van-sticky": "@vant/weapp/sticky/index",
    "van-empty": "@vant/weapp/empty/index",
    "van-submit-bar": "@vant/weapp/submit-bar/index",
    "van-field": "@vant/weapp/field/index",
    "van-uploader": "@vant/weapp/uploader/index"
  }
}
```

**策略**：渐进替换，不一次性重写全部页面；优先列表 Tag + 空状态 Empty。

可选后续：`weui-miniprogram`（更偏微信原生），与 Vant 二选一为主、避免双库过重。
